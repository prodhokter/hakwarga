# Checklist Upload Karya: Web In Action

Tim: **Manut Opo Jare Ibnu**

## 1. Yang Diisi di Form

| Kolom | Status | Yang harus diisi |
|---|---|---|
| **Nama Tim** | Otomatis | Terkunci karena tim sudah terverifikasi, tidak perlu diisi. |
| **Nama Project** | Isi | Nama aplikasi/website kamu. |
| **Pilihan Sub-Tema** | **Wajib (*)** | Pilih satu atau lebih (lihat bagian 2). |
| **Deskripsi Project** | Isi | Apa yang dilakukan project dan cara kerjanya. |
| **Thumbnail Karya** | **Wajib (*)** | Gambar JPG/PNG/WEBP, maks. **5 MB**, rasio **16:9**. |
| **Flow Aplikasi** | Isi | Alur penggunaan, contoh: `User buka app -> Login -> Dashboard -> Browse fitur -> Gunakan fitur spesifik`. |

Nama Project, Deskripsi, dan Flow Aplikasi tidak bertanda wajib di form, tapi sebaiknya tetap diisi lengkap karena dinilai juri.

## 2. Pilih Sub-Tema (minimal 1)

- [ ] **Open Government Data**: dashboard atau visualisasi data pemerintah (anggaran, realisasi proyek, statistik daerah).
- [ ] **Public Service Tracking**: pelacakan status layanan publik (pengaduan, perizinan, bantuan sosial).
- [ ] **Civic Reporting & Accountability**: platform pelaporan masyarakat (infrastruktur rusak, dugaan penyimpangan, isu lingkungan).
- [ ] **Data-Driven Decision Support**: insight dari data publik (perbandingan layanan antar daerah, tren anggaran, indikator kesejahteraan).

## 3. Yang Perlu Disiapkan (Fase Pengumpulan Sementara)

### Wajib sekarang
- [ ] **Link File Presentasi** (PowerPoint, Google Slides, atau Canva). Akses harus **publik (Viewer)** agar bisa dibuka dewan juri.
- [ ] **Link Repo GitHub (Utama)**: `https://github.com/prodhokter/kinerja` (Sudah siap & Public).
- [ ] **Link Surat Keterangan Orisinil Karya** (bermaterai Rp 10.000).
  - Di form, label ini tertulis "Opsional Sementara", tapi teks penjelasan fase ini menyebutnya **wajib diisi**. Anggap wajib supaya aman.
  - Langkahnya: buat surat pernyataan orisinalitas, tempel materai Rp 10.000, tanda tangan, scan, upload ke Google Drive, lalu set akses "Anyone with the link" sebagai Viewer.
  - Cek **Panduan Lomba** di footer untuk format suratnya.

### Opsional sekarang, wajib saat pengumpulan final
- [ ] **Link Draft Proposal** (Google Docs)
- [ ] **Link Deployment / Live Website**: `https://kinerja.web.id`
- [ ] **Link Video Pitching YouTube**, misalnya `youtube.com/watch?v=...` atau `youtu.be/...`

### Opsional
- [ ] **Link Repo GitHub kedua**, hanya jika Frontend dan Backend dipisah.
- [ ] **Link Lainnya**, misalnya panduan pengujian atau aset pendukung.

## 4. Sebelum Klik "Upload Karya"

- [ ] Semua link bisa dibuka dari akun lain atau mode incognito.
- [ ] Thumbnail berformat benar, ukuran di bawah 5 MB, dan rasio 16:9.
- [ ] Sub-tema sudah dipilih.
- [ ] Link ditulis lengkap dengan `https://`.
- [ ] Thumbnail akan tampil di galeri **Show It** saat Final Submission Babak Penyisihan, jadi pilih gambar yang representatif.
